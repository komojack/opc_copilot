# 续约规则

## 基本原则

续约的默认立场是**维持原条款**。要调整必须有依据，且调整方向对自己不利时需创始人确认。

## 续约条件判断

到期前 60 天启动评估，看三项：

1. **履约情况**：合作期内是否有逾期。有过逾期超 30 天的，折扣不得上调。
2. **合作体量**：年度实付金额是否达到原合同年额。未达 80% 的，不适用体量升档。
3. **利润率**：折扣后是否仍高于成本线。低于成本线一律不续。

## 折扣调整规则

| 情形 | 处置 |
|---|---|
| 客户要求维持原折扣 | 满足履约与体量条件即可直接确认 |
| 客户要求上调折扣 ≤ 3 个百分点 | 需同时满足：无逾期记录、体量达标、调整后不超所属档位上限 |
| 客户要求上调超过 3 个百分点 | 一律转创始人确认 |
| 客户要求超出档位上限 | 拒绝，转创始人确认 |

## 条款调整

以下条款的任何变更都必须创始人确认，Agent 不得自行答应：

- 账期延长
- 增加无理由终止条款
- 取消预付款要求
- 独家/排他约定
- 知识产权归属变更

## 升级确认条件

- 折扣上调超过 3 个百分点或超出档位上限
- 任何非折扣类条款变更
- 合同年额超过 20 万
- 客户有逾期记录
- 到期不足 15 天仍未谈定

其余情况可依据本规则与业务数据给出结论。
