# 供应商核价规则

## 费率依据优先级

供应商账单与约定不符时，按以下优先级认定"当初谈好的费率"：

1. 书面合同附件中的费率表
2. 正式报价单（带编号）
3. 邮件确认记录
4. 微信/聊天记录确认

**口头约定不作为核价依据。** 若只有口头约定，一律转创始人确认。

## 核价流程

1. 取账单的 `quantity × unit_price`，与约定费率算出的 `expected_amount` 比对。
2. 差额 = 实际 − 应付。
3. 检查是否有本应触发但未适用的优惠（如大批量折扣）。
4. 检查是否有需事先书面确认才能计费的上浮项（如技术类文档上浮）——**没有书面确认的上浮一律不认**。

## 差额处置

| 差额 | 处置 |
|---|---|
| 0 | 正常付款 |
| ≤ 200 元且 ≤ 5% | Agent 可直接说明，建议照付并提醒下期修正 |
| 超过 200 元或超过 5% | 转创始人确认，暂缓付款 |
| 已付款后才发现 | 一律转创始人确认追回事宜 |

## 升级确认条件

- 差额超过 200 元或超过 5%
- 费率依据只有口头约定
- 供应商单方面调价
- 已付款需要追回
- 涉及更换供应商

Agent 不得自行同意调价，也不得自行承诺付款。
