# 税务与记账分类

## 收入分类

| 类别 | 判断依据 |
|---|---|
| 服务收入 | 交付的是设计、内容、咨询等劳务成果 |
| 授权收入 | 交付的是既有作品的使用权，不含新创作 |
| 转售收入 | 代客户采购印刷、投放等，自己不加工 |

**转售部分必须与服务收入分开记账**，否则会虚增服务收入的税基。

## 支出分类

| 类别 | 说明 | 可抵扣 |
|---|---|---|
| 外包成本 | 供应商提供的劳务，需取得发票 | 是 |
| 采购成本 | 印刷、素材、软件订阅 | 是 |
| 经营费用 | 差旅、办公、通信 | 是，需与业务相关 |
| 个人支出 | 与经营无关 | 否，不得入账 |

## 追溯留痕要求

每笔收支必须能回答三个问题，缺一即为记录不合格：

1. **对应哪个客户/供应商**（实体编号）
2. **依据是什么**（报价单号、合同号、账单号）
3. **当时为什么这么定价/分类**（一句话理由）

这三项在发生时记，不要事后补——半年后报税时补不出来。

## 升级确认条件

- 收入性质介于服务与授权之间，界定不清
- 转售与服务混在同一笔款项里，需拆分
- 支出缺发票或凭证
- 涉及跨年度调整、红冲、坏账核销
- 个人与经营支出混同

以上一律转创始人确认。Agent 可以说明分类规则和判断思路，**但不得自行确定最终税务处理**——税务定性错误的后果由创始人承担。
