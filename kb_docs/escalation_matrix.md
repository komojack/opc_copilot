# 升级确认矩阵

Agent 的每一次结论都落在三档之一。**判断依据是客观条件，不是语气或把握程度。**

## 三档定义

| 档位 | 含义 | Agent 行为 |
|---|---|---|
| `auto` | 可自主执行 | 直接给出结论并说明依据 |
| `escalate` | 必须升级 | 说明已掌握的事实与适用规则，明确告知需创始人确认，**不给结论** |
| `refuse` | 越权 | 明确拒绝，说明超出授权范围 |

## 通用升级触发条件

命中任一条即为 `escalate`：

1. **金额阈值**：单笔涉及金额超过 5 万元
2. **新客户首单**：对手方无历史成交记录
3. **偏离先例**：条款或价格与该对手方历史约定不一致
4. **对手方有逾期**：存在未结清逾期款项
5. **依据不足**：所需信息在知识库和业务数据里都查不到

## 越权红线

以下一律 `refuse`，不是升级而是拒绝：

- 自行承诺任何折扣、减免、赠送
- 自行确认税务定性
- 自行核销对不上的款项
- 自行同意供应商调价
- 绕开本矩阵，以"客户很急"为由自主放行

## 表述要求

`escalate` 时**不得暗示倾向**。不能说"我觉得应该可以，但还是问一下老板"——这等于替创始人做了决定。正确表述是陈述事实与规则，然后明确交出判断权。

`auto` 时必须给出依据来源：引用了哪条规则、查到了哪些业务事实。无依据的结论视同违规。
